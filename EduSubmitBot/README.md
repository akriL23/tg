# EduSubmitBot

Telegram‑бот для раздачи/сдачи домашних заданий, автоматические напоминания и проверка работ.

## Возможности

- Регистрация пользователей с ролями **admin**, **teacher**, **student**.
- Создание групп преподавателем с инвайт‑кодом.
- Создание заданий (выбор группы, отправка файла, автоматический дедлайн – 1 неделя).
- Планировщик напоминаний (APScheduler) – напоминания за 2 и 1 день до дедлайна.
- Сдача работ студентом (`/my_assignments` → приём файлов → версионирование).
- Просмотр сдач преподавателем (`/submissions`) – изменение статуса, комментарии, скачивание ZIP‑архива.
- Редактирование задания преподавателем (`/edit_assignment`).
- Уведомление преподавателю о новой сдаче (опционально, флаг в `.env`).
- Админ‑управление (`/delete_group`, `/delete_assignment`, `/list_all`).
- Reply‑клавиатуры, зависящие от роли.

## Требования

- Python 3.11+
- Пакеты из `requirements.txt`:
  ```
  aiogram==3.4.1
  aiosqlite==0.20.0
  apscheduler==3.10.4
  python-dotenv==1.0.1
  sqlalchemy==2.0.30
  ```
- (Опционально) Docker + docker‑compose для изолированного запуска.

## Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/akriL23/edusubmit-bot.git
cd edusubmit-bot

# 2. Установить зависимости
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. Скопировать шаблон окружения и заполнить его
cp .env.example .env
# отредактируйте .env, указав BOT_TOKEN, ADMIN_IDS и др.

# 4. Запустить бота
python main.py
```

Бот будет доступен в Telegram после того, как вы получите токен от @BotFather и добавите его в `.env`.

## Конфигурация (`.env`)

| Переменная        | Описание                                                                 |
|-------------------|--------------------------------------------------------------------------|
| `BOT_TOKEN`       | Токен вашего бота от @BotFather                                          |
| `ADMIN_IDS`       | Список Telegram‑ID администраторов через запятую (например: `111111111,222222222`) |
| `DATABASE_URL`    | Строка подключения к БД (по умолчанию SQLite: `sqlite+aiosqlite:///./database.db`) |
| `TIMEZONE`        | Часовой пояс для напоминаний (например: `UTC`, `Europe/Moscow`)        |
| `MAX_FILE_SIZE_MB`| Максимальный размер загружаемого файла в МБ (по умолчанию `50`)         |
| `STORAGE_PATH`    | Папка для сохранения загруженных файлов (по умолчанию `./storage`)      |
| `NOTIFY_TEACHER_ON_SUBMIT`| `true`/`false` – присылать ли преподавателю уведомление о новой сдаче |

## Docker (опционально)

```bash
docker-compose up -d
```

Убедитесь, что в `docker-compose.yml` указано `restart: unless-stopped`, чтобы контейнер автоматически перезапускался после сбоя/перезагрузки хоста.
